# Nikita Kustov — Product Designer Portfolio

Deploy-ready static portfolio for GitHub Pages.

## Contents
- `index.html` — bilingual EN/RU portfolio; English is the default language.
- `styles.css` — complete responsive styles from the final v6 layout.
- `assets/` — all images and the SELA prototype video used by the website.
- `.nojekyll` — tells GitHub Pages to serve the repository as a plain static site.

## Publish on GitHub Pages
1. Create a new GitHub repository.
2. Upload **all files and the `assets` folder from this directory to the repository root**.
3. Open **Settings → Pages**.
4. Set **Source: Deploy from a branch**.
5. Select **main** and **/(root)**, then save.
6. Open the GitHub Pages URL and verify the site before connecting a custom domain.

## Custom domain
Do not add a `CNAME` file until the final domain is known. The custom domain can be entered later in **Settings → Pages → Custom domain**; GitHub will manage the repository CNAME entry.
